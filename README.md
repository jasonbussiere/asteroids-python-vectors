# Asteroids-Vectors

A small Python game built with my son to make vector math and physics feel real, visual, and fun.

This project started as a simple idea: turn abstract concepts like position, velocity, acceleration, and rotation into something we could see moving on screen. Instead of learning vectors only from formulas and diagrams, we built a playable Asteroids-style game where the math drives the game itself.

The result is a hands-on learning project that shows how math can be used to create motion, collisions, and interactive systems in code.

## Why I built it

I wanted my son to understand that math is not just something you do on paper — it is part of what makes games, simulations, and motion work in the real world.

By building a small arcade game together, we could explore:
- vectors and direction
- speed and magnitude
- position updates
- rotation and movement
- collisions and game physics
- how code turns mathematical ideas into visible behavior

## Project goals

- create a playable Asteroids-inspired game in Python
- teach vector math through code
- make physics concepts more concrete and visual
- show that math can be practical and fun
- build a project we could learn from together

## What makes it educational

The game uses a custom 2D vector system rather than a physics engine, so every movement and interaction is directly connected to the math behind it.

This includes:
- moving the ship based on direction and acceleration
- rotating the ship and firing in the correct direction
- updating asteroid positions using velocity vectors
- handling collisions based on object distance
- creating an interactive system that demonstrates how math shapes behavior

It turns abstract ideas into something tangible: if the vector changes, the movement changes immediately.

## Tech stack

- Python 3
- Pygame
- Custom 2D vector math
- Object-oriented programming
- Game loop and simulation logic

## How to run

1. Clone the repository:
```bash
git clone https://github.com/jasonbussiere/asteroids-python-vectors.git
cd asteroids-python-vectors
```

2. Install dependencies:
```bash
pip install pygame-ce
```

3. Run the game:
```bash
python main.py
```
